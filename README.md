# 🐍 贪吃蛇大作战

基于 Python + Pygame 的贪吃蛇游戏，支持 AI 自动寻路、皮肤切换、关卡系统、网络排行榜。

## 功能清单

| 模块 | 功能 |
|------|------|
| 🎨 皮肤系统 | 4 款皮肤（经典/霓虹/深海/烈焰），主菜单选择 |
| 🚧 关卡系统 | 每吃 5 个食物升级，速度递增，新增障碍物 |
| 🎵 音效 | 纯代码生成（正弦波合成），吃食物/死亡音效 |
| 🤖 AI 模式 | BFS 最短路径寻路 + 保底策略，空格键随时切换 |
| 🌐 排行榜 | FastAPI 后端 + requests 客户端，前 10 名持久化 |
| ⏸ 暂停 | P 键暂停/继续 |
| 🏆 胜利条件 | 蛇身填满整个网格即为通关 |
| 💾 本地最高分 | 自动保存到 scores_local.json |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动排行榜服务器（可选）

在单独的终端中运行：

```bash
python server.py
```

或使用 uvicorn：

```bash
uvicorn server:app --reload --port 8000
```

> 如果不需要网络排行榜功能，可以跳过此步骤。游戏在服务器不可用时仍可正常运行。

### 3. 启动游戏

```bash
python main.py
```

## 操作说明

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → / WASD | 控制蛇的移动方向 |
| 空格键 | 切换 手动/AI 自动寻路 模式 |
| P | 暂停 / 继续 |
| Q（暂停时）| 返回主菜单 |
| Enter | 主菜单开始游戏 / 提交分数 |
| Esc | 取消 / 返回上一级 |

## 技术要点

- **网格系统**：800×600 屏幕，20px 格子，40×30 网格坐标
- **BFS 寻路**：将蛇身（除尾部外）和障碍物视为不可通行，搜索最短安全路径
- **皮肤系统**：通过颜色字典实现，所有图形均为 Pygame 几何绘制
- **音效合成**：使用 `numpy` + `pygame.sndarray` 生成正弦波，无需外部音频文件
- **网络架构**：FastAPI 提供 RESTful API，游戏端通过 requests 通信
